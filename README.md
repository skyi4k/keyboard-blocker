# 🐱 Cat Keyboard Blocker

> Ваша кошка любит лежать на клавиатуре? Эта утилита поможет!

**Cat Keyboard Blocker** — лёгкая Windows-утилита, которая блокирует клавиатуру одним кликом или горячей клавишей. Живёт в системном трее, не мешает работе мыши.

## ✨ Возможности

- 🔒 **Блокировка клавиатуры** — все нажатия поглощаются, мышь работает
- ⌨️ **Горячая клавиша** — настраиваемая комбинация (по умолчанию `Ctrl+Shift+K`)
- 🎨 **Смена стиля иконки** — клавиатура, кошачья лапка 🐾, мордочка кота 🐱, замок 🔒 или кружок (зелёный = свободно, красный = заблокировано)
- 🔄 **Автообновления с GitHub** — программа сама проверяет релизы, показывает окно с описанием и обновляется в 1 клик
- 🚀 **Автозапуск** — опционально запускается вместе с Windows
- 💾 **Настройки сохраняются** — конфигурация в `%APPDATA%\CatKeyboardBlocker\config.json`
- 🛡️ **Ctrl+Alt+Del всегда работает** — защита на уровне ядра Windows

## 📦 Установка

### Вариант 1: Готовый EXE (рекомендуется)

1. Скачайте `CatKeyboardBlocker.exe` из [Releases](../../releases)
2. **ПКМ → Запуск от имени администратора**
3. Готово! Иконка появится в трее

### Вариант 2: Из исходников

```bash
git clone https://github.com/skyi4k/keyboard-blocker.git
cd keyboard-blocker
pip install -r requirements.txt
python cat_blocker.py
```

> ⚠️ **Важно:** Для блокировки клавиатуры требуются права администратора.

## 🎮 Использование

| Действие | Как |
|----------|-----|
| Включить/выключить блокировку | **Клик по иконке в трее** или **горячая клавиша** |
| Сменить горячую клавишу | ПКМ по иконке → «Горячая клавиша: ...» |
| Сменить стиль иконки | ПКМ по иконке → «Стиль иконки» → выбрать стиль |
| Проверить обновления | ПКМ по иконке → «Обновления» → «Проверить обновления сейчас» |
| Автопроверка обновлений | ПКМ по иконке → «Обновления» → включить галочку |
| Включить автозапуск | ПКМ по иконке → «Автозапуск с Windows» |
| Выйти | ПКМ по иконке → «Выход» |

### Горячая клавиша по умолчанию: `Ctrl+Shift+K`

Горячая клавиша работает **даже когда клавиатура заблокирована** — это единственный способ разблокировать без мыши.

## 🔧 Сборка EXE

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name CatKeyboardBlocker cat_blocker.py
```

Готовый файл: `dist/CatKeyboardBlocker.exe`
